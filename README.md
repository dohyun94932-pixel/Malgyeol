# 말결 프로젝트
### **By AI, As a Team, Solve Important problems.**

#### **팀 미션 : 바이브코딩으로 우리 조 앱 만들기**

- 코딩을 몰라도 괜찮아요 !
AI와 대화하며 동기들과 함께 실제로 작동하는 가벼운 웹앱 하나를 만드는 미션입니다.

모든 앱은 **Claude** 로 만드는 **3~5화면짜리 웹앱**입니다.
설치 없이 링크로 바로 열리고, **1~2분 안에 시연할 수 있을 만큼 가벼워야 합니다.**
(발표 당일 300~400명이 동시에 접속이 필요합니다.)

### 현재 구현 (기획안 v1.1 기준, 2026-10-04 갱신)
- 화면 1 · 홈: 자유 입력창이 먼저, 아래에 "또는 상황을 골라 시작하기" 카드 6개, 맨 아래 "내 말투 설정 >"
  - 카드 없이 입력해도 [정리하기] 가능 → 질문 준비실로 정리 (화면 2 상단에 카드 이름과 안내 표시)
  - 카드: 질문 준비실 / 부탁 한 장 / 피드백 연습장 / 의도 확인 카드(준비 중 배지, 누르면 안내만) / 한 줄 상황보고 / 거절도 괜찮아
- 화면 2 · 상황·의도 구체화: 받는 사람(상사/선배/동료/클라이언트), 카드별 입력 칸, 빈칸은 노란색 + 되묻는 질문 (필수 칸만 [표현 만들기]를 막음)
- 화면 3 · 표현 비교: 간결하게 / 부드럽게 / 명확하게, 의도 체크, "왜 이렇게 바꿨나요?", [복사] [내 말투에 반영], 아래 작은 글자 버튼 [다시 만들기] [구조 수정] [내 말투 설정] [처음으로]
- 상단 바는 없음 (시안 기준). 화면 이동은 각 화면 아래 글자 버튼과 홈의 "내 말투 설정 >"으로 한다
- 화면 4 · 내 말투: 첫 방문 A/B("어느 쪽이 나답나요?"), 문장 길이 · 요청 방식 · 끝맺음, 피하고 싶은 표현, 선호 예문(삭제 가능), [저장]
  - 말투 설정은 표현 3종 모두에 반영. 피하고 싶은 표현은 앱이 붙이는 문장(인사·끝인사 등)에서 뺀다
  - 결과를 만든 뒤 들어오면 [← 결과로 돌아가기]로 돌아가 [다시 만들기] 가능
- 기밀정보 안내: 홈과 화면 2
- 예전 버전 localStorage 값(없어진 선택지 등)은 기본값으로 바꿔 읽음
- 반응형 레이아웃 (iPhone Safari, 카카오톡 인앱 브라우저에서 확인 완료 · v1.1 변경 후 모바일 재확인 필요)

### 임시 구현
- 샘플 데이터는 더미 데이터
- AI 호출은 가짜 AI(`ai.js`)로 대체. API 키가 제공되지 않아 실제 AI 연결은 보류하고, 카드별 샘플 응답과 문장 틀로 메시지를 조립
- 콘텐츠팀 최종 문구 반영 필요
- 디자인팀 design.md 반영 필요 — 시안 기준 1차 반영 (기획안 6장 화면 시안 · 2026-10-04, 색·크기는 `style.css` 맨 위 `:root` 변수)

### 데이터 반영 위치
- `content.js`: 콘텐츠팀·데이터팀에서 받은 카드·입력 칸 문구, 되묻는 질문, 온보딩 문장, 입력 예시 문장, 샘플(더미) 응답, 메시지 문장 틀, 화면 안내 문구(토스트·오류 알림 등)를 이 파일에 반영합니다. 현재 값은 모두 임시 데이터입니다.
  - 넣는 위치와 바꾸면 안 되는 이름은 파일 맨 위 주석에 적혀 있습니다.
  - 이름이 서로 어긋나면 브라우저 콘솔(`Cmd+Option+I`)에 `[content.js]` 오류가 뜹니다.
- 화면 제목, 버튼 이름, 보안 안내 문구는 `index.html`
- 디자인팀 design.md는 `style.css`와 `index.html`에 반영합니다. 색·크기는 `style.css` 맨 위 `:root` 변수에 모여 있습니다.

### 내부 리뷰용 화면 바로가기
