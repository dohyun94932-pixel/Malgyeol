## 말결 개발 현황

### 배포
Vercel: https://malgyeol-neon.vercel.app/

### 현재 구현
- 홈 입력
- 구조화 확인
- 메시지 결과
- 내 말투 설정
- 반응형 레이아웃 (실기기 점검 전)

### 임시 구현
- 샘플 데이터는 더미 데이터
- AI 호출은 가짜 AI(`ai.js`)로 대체. 실제 AI는 아직 연결 전
- 콘텐츠팀 최종 문구 반영 필요
- 디자인팀 design.md 반영 필요

### 데이터 반영 위치
- `content.js`: 콘텐츠팀·데이터팀에서 받은 카드·입력 칸 문구, 되묻는 질문, 온보딩 문장, 샘플(더미) 응답, 메시지 문구를 이 파일에 반영합니다.
  - 넣는 위치와 바꾸면 안 되는 이름은 파일 맨 위 주석에 적혀 있습니다.
  - 이름이 서로 어긋나면 브라우저 콘솔(`Cmd+Option+I`)에 `[content.js]` 오류가 뜹니다.
- 화면 제목, 버튼 이름, 보안 안내 문구는 `index.html`
- 디자인팀 design.md는 `style.css`와 `index.html`에 반영합니다.

### 내부 리뷰용 화면 바로가기
- 주소 뒤에 `?review`를 붙이면 화면 아래에 화면 바로가기가 나타납니다. 예: `https://malgyeol-neon.vercel.app/?review`
- 최종 배포 전에 제거: `review.js`, `review.css`를 지우고 `index.html`의 관련 3줄(`<link>`, `<nav>`, `<script>`)을 지웁니다.
