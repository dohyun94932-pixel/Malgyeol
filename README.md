### 임시 구현
- 샘플 데이터는 더미 데이터
- AI 호출은 가짜 AI(`ai.js`)로 대체. API 키가 제공되지 않아 실제 AI 연결은 보류하고, 카드별 샘플 응답과 문장 틀로 메시지를 조립
- 콘텐츠팀 최종 문구 반영 필요
- 디자인: 코딩 레퍼런스 2장 기준(10/04 앱 · 파란색). v1.1 시안(주황) 반영분은 10/05 되돌림 — docs/decision-log.md 참고

### 데이터 반영 위치
- `content.js`: 콘텐츠팀·데이터팀에서 받은 카드·입력 칸 문구, 되묻는 질문, 온보딩 문장, 입력 예시 문장, 샘플(더미) 응답, 메시지 문장 틀, 화면 안내 문구(토스트·오류 알림 등)를 이 파일에 반영합니다. 현재 값은 모두 임시 데이터입니다.
  - 넣는 위치와 바꾸면 안 되는 이름은 파일 맨 위 주석에 적혀 있습니다.
  - 이름이 서로 어긋나면 브라우저 콘솔(`Cmd+Option+I`)에 `[content.js]` 오류가 뜹니다.
- 화면 제목, 버튼 이름, 보안 안내 문구는 `index.html`
- 디자인팀 design.md는 `style.css`와 `index.html`에 반영합니다. 색·크기는 `style.css` 맨 위 `:root` 변수에 모여 있습니다.

### 내부 리뷰용 화면 바로가기
- 주소 뒤에 `?review`를 붙이면 화면 아래에 화면 바로가기가 나타납니다. 예: `https://malgyeol-neon.vercel.app/?review`
- 최종 배포 전에 제거: `review.js`, `review.css`를 지우고 `index.html`의 관련 3줄(`<link>`, `<nav>`, `<script>`)을 지웁니다.
