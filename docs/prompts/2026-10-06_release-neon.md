[0단계 · 출발점 정하기]
- git fetch로 origin·mine을 모두 최신으로 받고, feature/final-polish · feature/gemini-ai · feature/content-team-ref 중
  가장 최신 작업이 들어 있는 브랜치를 찾아 무엇이 들어 있는지 요약해 줘.
- 그 브랜치에서 새 브랜치 release/neon 을 만들어 작업해. 진행 전에 계획을 보여 주고 내 승인을 받아.

- api/ 폴더(structurize, generate, health, _lib)를 지우고, ai.js의 서버 호출·10분 캐시·1분 호출 제한·시간 초과·대체 처리 코드를 지워.
  가짜 AI로 쓰던 로직을 앱의 정식 엔진으로 쓴다. 함수 이름(structurize, generateMessages)과 입출력 형식은 유지하고,
  파일 이름은 역할이 드러나게 바꾸는 게 좋을지(예: engine.js) 제안해 줘.
- 화면과 cards.json에서 다음을 지워: "입력 내용은 AI 서비스로 전송돼요…" 안내, "지금은 AI 대신 연습용 예시 문장…" 회색 안내,
  ?review의 "생성: Gemini/가짜 AI" 출처 표시. 기밀 안내("클라이언트명·금액 등…")는 콘텐츠팀 고정 문구라 그대로 둬.
- 화면에 보이는 문구 중 'AI'라는 말이 들어간 곳을 모두 찾아 목록으로 보여 주고, 앱이 직접 정리하는 표현으로 바꿀 안을 제안해 줘
  (예: "AI가 채운 칸" → "한 줄에서 찾은 내용"). cards.json 문구로 관리해.
- README, CLAUDE.md에서 Gemini·환경변수·?mock 설명을 지우고 "외부 AI API 사용 안 함. 샘플 데이터와 규칙 기반 엔진, Claude와 협업해 개발"로 바꿔 줘.
  GEMINI·API 키 관련 문자열이 저장소에 남아 있지 않은지 검색해서 확인해 줘.

[2단계 · 엔진 품질 — 이제 이 엔진이 앱의 실력이다]
- 구조화(structurize):
  · data/malgyeol_sample_data.json 30건과 cards.json demo를 활용해, 입력한 한 줄이 샘플과 비슷하면(키워드·문장 유사도) 그 샘플의 칸 값을 쓴다.
    단 한 줄에서 알 수 있는 칸만 채우고 나머지 필수 칸은 비워서 노란 칸 되묻기가 나오게(시연 데모는 'tried'가 비어야 함).
  · 샘플과 맞지 않는 입력은 문장 연결어("~했는데", "~인데", "~지만", "~해서", "~인지")로 나눠 상황·막힌 지점·묻고 싶은 것 등에
    규칙으로 배치하고, 판단이 안 되는 칸은 비워서 되묻는다. 지어내지 않는다.
- 메시지 생성(generateMessages): 지금까지 요청한 규칙을 모두 엔진에서 지켜 줘.
  · 칸 값 모양(완성 문장·질문·명사구·메모체·"~지"형)에 맞는 틀, 메모체 변환(~해봄→~해 봤습니다, ~해야함→~해야 한다고 생각합니다),
    질문 뒤 틀 덧붙임 금지, "~지"형에 조사 금지, 기한 "까지" 중복 금지, 보조 용언 띄어쓰기
  · 메시지 한 통 = 문체 하나(클라이언트=합니다체, 동기=반말, 선배·인차지=말투 설정), 존댓말 속 '나'→'저'
  · B1 빈 칸 내용·요청 문장 추가 금지, B2 질문 준비실은 '묻고 싶은 것'이 마지막 문장, B3 수정 이유는 채운 칸·탭 기준 2~3줄
  · 받는 사람별 호칭·거리감(코딩 레퍼런스 2장 6절), 마스킹 유지, evidence는 본문에 글자 그대로
  · 탭 3종이 실제로 다르게 보이게(내 말투안 / 더 간결하게 / 더 부드럽게)
- [다시 만들기]: 같은 입력이면 같은 문장이 나와 의미가 없으니, 연결어·인사·끝인사 후보를 여러 개 두고 누를 때마다 다른 조합을 쓰게 해 줘.
  내용(칸 값)은 바꾸지 않는다.

[3단계 · 화면 마무리] (이미 된 것은 건너뛰고 알려 줘)

  근거 구절 일치를 점검하고, 문제 0건이 될 때까지 고쳐 줘. 결과를 docs/qa/에 저장.
- 지금까지 나온 오류 문장(요청해봄을 해 봤습니다, 제외해주실 수 있나요입니다, 새어봄을 해 봤습니다, 불이익을 없는지,
  어떻게 해야나요 부탁드려요, 좋겠어요를 부탁드립니다, 내로까지)도 시험 사례로 넣어 0건 확인.
