## 프롬프트 원문 ① 무료 등급 조건 (사용자가 먼저 보냄 · 본 프롬프트보다 우선)

```
[무료 등급 조건 — 위 내용보다 우선]
- 나는 Gemini 무료 등급을 쓴다. 무료 등급은 입력이 Google 제품 개선에 쓰이고 사람이 검토할 수 있다.
  홈과 구조화 확인 화면의 기밀 안내 아래에 "입력 내용은 AI 서비스로 전송돼요. 실제 회사명·금액·이름은 넣지 마세요."를
  cards.json uiCopy에 추가해 보여 줘.
- 무료 등급은 분당·일일 호출 한도가 낮다. 공식 문서에서 지금 모델의 무료 한도를 확인해 알려 주고,
  한도를 넘으면(429) 즉시 가짜 AI로 대체되게 해 줘. 재시도는 하지 마.
- 호출을 아끼기 위해 같은 입력(카드·칸·받는 사람·말투가 모두 같음)은 브라우저에 결과를 잠시 저장해 두고 다시 부르지 마.
- 발표 당일 수백 명이 동시에 쓰면 대부분은 가짜 AI로 대체될 수 있다는 점을 README에 적어 줘.
- decision-log의 AI 서비스 기록은 "Gemini 무료 등급"으로 적고, 그 한계(데이터 사용, 호출 한도)도 함께 적어 줘.
- 배포는 내 저장소(mine)와 내 Vercel 기준이다. 환경변수는 내 Vercel 프로젝트에 GEMINI_API_KEY로 등록했다.
```

## 프롬프트 원문 ② 본 작업

```
CLAUDE.md 규칙을 따르되, 이번 작업에 한해 '실제 AI 연결 금지' 규칙을 풀고 가짜 AI를 Google Gemini API로 바꾸자.
먼저 ai.js, main.js, data/cards.json을 읽고, 가짜 AI가 어디서 호출되는지와 바꿀 계획을 쉬운 말로 보여 준 뒤 승인을 받아.

[구조]
- 브라우저 → ai.js → Vercel 서버 함수(api/structurize.js, api/generate.js) → Gemini API.
  키는 서버 환경변수 GEMINI_API_KEY에서만 읽고, 브라우저 코드·로그·커밋·화면 어디에도 나오지 않게 해.
  키는 URL 쿼리(?key=)가 아니라 요청 헤더로 보내 줘.
- 모델은 환경변수 GEMINI_MODEL로 바꿀 수 있게 하고, 기본값은 Google 공식 문서(ai.google.dev)에서 지금 쓸 수 있는
  빠르고 저렴한 Flash 계열 모델을 확인해서 넣어 줘. 모델명을 추측하지 말고 문서를 확인해.
  응답 속도가 중요하니, 그 모델에 '생각(thinking)' 설정이 있으면 최소로 줄이는 방법도 문서에서 확인해 적용해 줘.
- 외부 패키지 없이 Node 내장 fetch로 REST API를 호출해. SDK가 꼭 필요하면 이유를 먼저 설명해.
- 시스템 지시문은 api/_lib/prompts.js에 따로 두고, 공통 코드도 api/_lib/에 둬.
  나중에 다른 AI로 바꿀 수 있게 'AI 호출 부분'을 한 파일(api/_lib/llm.js)로 분리해 줘.

[입출력 — 지금 ai.js 함수 이름과 형식을 그대로 유지]
- structurize: 카드 정의(cards.json의 해당 카드)와 한 줄 입력 → { fields: {key: 값 또는 null}, followups: {...} }
- generateMessages: 카드 정의, 채운 칸, 받는 사람(cards.json partners), 말투 프로필(malgyeol.profile), 선호 문장(최대 5개)
  → 지금 ai.js가 돌려주는 형식(variants: mine/concise/soft, text, evidence, reasons)을 확인해서 그대로 맞춰 줘.
- 카드 정의를 요청에 담아 보내서, cards.json을 고쳐도 서버 코드는 고칠 필요가 없게 해.
- JSON 형식이 깨지지 않도록 Gemini의 구조화 출력(JSON 응답 형식 + 응답 스키마 지정)을 공식 문서에서 확인해서 써 줘.

[안전장치]
- 가짜 AI는 지우지 말고 대체용으로 남겨. 서버 오류, 시간 초과(구조화 8초·생성 15초 정도), 호출 한도 초과(429),
  JSON 형식 오류(1회 재시도 후), 네트워크 끊김이면 자동으로 가짜 AI 결과를 보여 줘.
  대체됐을 때는 결과 화면에 작은 안내 한 줄을 보여 줘(문구는 cards.json uiCopy에 추가, 해요체).
- 주소에 ?mock 을 붙이면 항상 가짜 AI를 쓰게 해 줘(시연 비상용).
- 서버에서도 근거 구절이 본문에 글자 그대로 있는지 확인하고, 없으면 그 항목을 비워서 보내.
- Gemini가 안전 필터로 응답을 막거나 빈 응답을 주면 오류로 처리해 가짜 AI로 대체해.
- POST만 허용, 칸당 글자 수 제한(예: 500자), 사용자 입력과 AI 응답은 서버 로그에 남기지 않기.
- 한 브라우저에서 짧은 시간에 너무 많이 호출하지 않도록 간단한 제한(예: 1분 10회)을 둬.

[로컬 확인]
- .env.local의 GEMINI_API_KEY로 내 PC에서 실제 호출을 시험할 방법을 알려 줘(새 패키지 설치 없이 가능한 방법 우선).
  키 값은 절대 출력하지 마.
- 키가 없거나 틀리면 가짜 AI로 대체되는지도 확인해 줘.

[마무리]
- 한 번 쓸 때 드는 대략적인 토큰 수와, 발표 당일 400명이 2번씩 쓰면 드는 예상 비용을 공식 가격표 기준으로 계산해 줘.
  내 등급(무료/유료)의 분당 호출 한도로 400명 동시 사용이 가능한지도 알려 줘.
- README에 Vercel 환경변수(GEMINI_API_KEY, GEMINI_MODEL) 등록 방법과 ?mock 사용법을 적고,
  CLAUDE.md의 '실제 AI 연결 금지' 줄을 "AI는 Gemini(api/ 서버 함수). 실패 시 가짜 AI로 자동 대체"로 바꿔 줘.
- decision-log에 "AI 서비스: Gemini(유료 등급) 선택 이유"를 기록하고, docs/prompts/에 이번 프롬프트를 남긴 뒤 커밋(push는 하지 마).
```

## 진행과 결정

| 순서 | 내용 |
|---|---|
| 1 | ①만 먼저 도착 → AI가 본 프롬프트가 빠졌다고 알리고 기다림 (실제 AI가 없는데 "AI 서비스로 전송" 안내만 넣으면 사실과 다른 문구가 되므로) |
| 2 | ② 도착 → 공식 문서 확인: 모델 목록·가격·생각(thinking)·구조화 출력·호출 한도 페이지. **무료 한도 숫자는 문서에 없고 AI Studio에서만 확인 가능**하다고 알림 |
| 3 | 사람 결정: 계획 승인 · 기본 모델 `gemini-3.5-flash-lite` · 시험은 `mine`에 시험 브랜치 push 후 Vercel 미리보기 |
| 4 | ①과 ②가 충돌: ②는 decision-log에 '유료 등급', ①은 '무료 등급'으로 → ①이 우선이라 **무료 등급**으로 기록. ②의 "JSON 오류 1회 재시도"와 ①의 "429 재시도 금지"는 둘 다 지킴 |
| 5 | CLAUDE.md에는 '실제 AI 연결 금지' 줄이 실제로 없어서 '반드시 지킬 것'에 새 줄로 추가 |

## 확인한 것

| 확인 | 결과 |
|---|---|
| 서버 함수 없이(내 PC `py -m http.server`) 열기 | 구조화·생성 모두 가짜 AI로 대체, 결과 화면에 대체 안내, 의도 체크 ✓ 5개 |
| `?mock` | 서버 호출 0회, 대체 안내 안 보임 |
| 서버 함수 코드 (Node가 없어 브라우저에서 모듈을 불러 가짜 요청으로 실행) | 키 없음 → 502 `no_key`(브라우저가 가짜 AI로 대체) · GET → 405 · 500자 초과 → 400 · 같은 브라우저 11번째 호출 → 429 |
| 점검 페이지 (`scripts/qa.html`) | 기존 점검 0건 · 문체 혼합 0건 유지 (점검은 가짜 AI를 직접 써서 AI 호출을 쓰지 않음) |
| Vercel 미리보기 (`mine`의 feature/gemini-ai) | 빌드 성공. 단, 미리보기가 **Vercel 로그인으로 보호**돼 있어 AI가 직접 실제 Gemini 호출을 확인하지 못함 → 사용자 확인 필요 |

## 대략적인 사용량과 비용 (공식 가격표 2026-10 · `gemini-3.5-flash-lite` 유료 가격 기준)

| 항목 | 값 |
|---|---|
| 한 번 쓸 때 (구조화 1회 + 생성 1회) | 입력 약 2,500 토큰 · 출력 약 1,500 토큰 (시스템 지시문·카드 정의 포함, 한국어 기준 어림값) |
| 400명 × 2번 = 800번 | 입력 약 200만 · 출력 약 120만 토큰 → 약 $0.60 + $3.00 = **약 $3.6 (약 5천 원)** |
| 무료 등급 | 비용 0원. 대신 입력이 제품 개선에 쓰이고 호출 한도가 낮음 |
| 동시 사용 | 800번 × 2호출 = 약 1,600호출. 5분 안에 몰리면 분당 약 300호출 → 무료 등급 한도로는 어려워 대부분 가짜 AI로 대체될 가능성이 큼. 정확한 한도는 AI Studio → Rate limits에서 확인 |
